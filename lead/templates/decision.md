# Template: decision (ADR) and approval request

> Location: `docs/decisions/NNNN-short-title.md`, numbered consecutively. Decisions are never deleted, only replaced by new ones ("replaced by 0012").

```markdown
# NNNN: <title>

- Status: proposed | decided | replaced by NNNN
- Date: <date> · decided by: lead | visionary
- Affects: <modules, tasks, milestones>

## Problem
<What has to be decided, and why now?>

## Options
| Option | Pros | Cons | Effort / risk |
|---|---|---|---|
| A | | | |
| B | | | |

## Lead's recommendation
<option + reason in 2–4 sentences>

## Decision
<What applies now?> (for the visionary's topics, fill in only after their answer)

## Consequences
- Tasks that are created / closed: …
- Documentation to update: …
```

## Short form for approval requests to the visionary

```markdown
**Approval needed:** <one sentence>
**Why now:** <what is blocked>
**Recommendation:** <option> because <reason>
**Alternatives:** <short>
**Costs/consequences:** <credits, time, scope>
**Without an answer by <date>:** <what the lead does instead, e.g. park it and continue with X>
```
