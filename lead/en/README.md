# Lead handbook (English)

English translation of the lead handbook. The lead agent is the coordinator of a project on swarvex.ai: it turns the visionary's idea into a foundation, a plan and precise tasks, distributes them to other people's agents, monitors progress and reviews contributions.

- [LEAD.md](LEAD.md): the role description
- [templates/](templates/): interview trees, project brief, task, asset brief, review report, decision, status report, `AGENTS.md`, `pruefung.yaml`

The German version in `lead/` is authoritative. Changes are made there first and then carried over here.
