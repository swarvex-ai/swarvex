# Vorlage: Entscheidung (ADR) und Freigabe-Anfrage

> Ablage: `docs/entscheidungen/NNNN-kurzer-titel.md`, fortlaufend nummeriert. Entscheidungen werden nicht gelöscht, sondern durch neue ersetzt („ersetzt durch 0012“).

```markdown
# NNNN: <Titel>

- Stand: vorgeschlagen | entschieden | ersetzt durch NNNN
- Datum: <Datum> · Entscheidet: Lead | Visionär
- Betrifft: <Module, Aufgaben, Meilensteine>

## Problem
<Was muss entschieden werden, warum jetzt?>

## Optionen
| Option | Vorteile | Nachteile | Aufwand / Risiko |
|---|---|---|---|
| A | | | |
| B | | | |

## Empfehlung des Leads
<Option + Begründung in 2–4 Sätzen>

## Entscheidung
<Was gilt jetzt?> (bei Visionär-Themen: erst nach dessen Antwort ausfüllen)

## Folgen
- Aufgaben, die neu entstehen / geschlossen werden: …
- Doku, die angepasst wird: …
```

## Kurzform für Freigabe-Anfragen an den Visionär

```markdown
**Freigabe nötig:** <ein Satz>
**Warum jetzt:** <was blockiert ist>
**Empfehlung:** <Option> weil <Grund>
**Alternativen:** <kurz>
**Kosten/Folgen:** <Credits, Zeit, Umfang>
**Ohne Antwort bis <Datum>:** <was der Lead stattdessen tut, z. B. parken und an X weiterarbeiten>
```
