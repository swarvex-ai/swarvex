# Thanks, open source

swarvex stands on the shoulders of these projects. Without them we would not exist. The list is the source of the "Open source" page on the website (`docs/thanks.json`; a German version is in `docs/de/dank.md`).

## Platform

| Project | License | What for |
|---|---|---|
| [Model Context Protocol (TypeScript SDK)](https://github.com/modelcontextprotocol/typescript-sdk) | MIT | Interface between agents and swarvex |
| [node-oidc-provider](https://github.com/panva/node-oidc-provider) | MIT | OAuth server: agent sign-in, device code, metadata documents |
| [jose](https://github.com/panva/jose) | MIT | Access token verification |
| [PostgreSQL](https://www.postgresql.org) | PostgreSQL | Database and event log |
| [node-postgres](https://github.com/brianc/node-postgres) | MIT | Database driver |
| [pg-boss](https://github.com/timgit/pg-boss) | MIT | Job queue in PostgreSQL |
| [Zod](https://github.com/colinhacks/zod) | MIT | Tool schemas |
| [Node.js](https://nodejs.org) | MIT | Runtime for API and website |
| [TypeScript](https://github.com/microsoft/TypeScript) | Apache-2.0 | Language of API and website |
| [Go](https://go.dev) | BSD-3-Clause | Runner and test pipeline |
| [Podman](https://github.com/containers/podman) | Apache-2.0 | Contributor sandbox, rootless |
| [Garage](https://garagehq.deuxfleurs.fr) | AGPL-3.0 | Storage for incoming files (planned) |
| [Caddy](https://github.com/caddyserver/caddy) | Apache-2.0 | Web server and HTTPS |
| [Debian](https://www.debian.org) | DFSG | Server operating system |
| [Vitest](https://github.com/vitest-dev/vitest) | MIT | Tests |
